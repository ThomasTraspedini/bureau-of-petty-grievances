# Changelog

This file records product-repository releases. Versions intentionally omit dates; Git history and tags provide chronology.

## [0.2.0]

### Added

- A repository-native interactive prototype of the complete primary journey, from civic access through determination, consultation, public sharing, and successor authorization.
- A responsive Bureau identity using an owned procedural mark, civic-blue and warm-ivory palette, optimistic apricot accent, and self-hosted open-source typography.
- Designed validation, restricted-content, processing, failure, preserved-draft, and restored-credit states.
- Deterministic prototype evidence that connects submitted Chronology facts to findings, mitigation, remedy, timeline, and share preview.
- Automated prototype behavior and localization-boundary verification within the canonical repository checks.

### Changed

- The capability roadmap now records the product and interaction prototype as complete and the application foundation as ready.
- Architecture and testing documentation now incorporate evidence from the rendered interaction direction.

## [0.1.1]

### Added

- An ordered, dependency-aware capability roadmap.
- Deterministic behavior for the human command `next task`.
- A decision record separating the public product roadmap from private execution coordination.

### Changed

- Repository validation now requires the public roadmap.

## [0.1.0]

### Added

- The project operating contract for agents and contributors.
- Public product, architecture, testing, and operations documentation.
- Internationalization as a foundational product constraint.
- Agent-task release versioning and a repository-boundary decision record.
- An automated repository validation script.

# Decision records

This directory contains durable decisions that materially shape the product or the way it is built. Records explain context, decision, consequences, and what remains intentionally open.

Create a decision record when a future agent would otherwise need to rediscover a consequential tradeoff. Do not create one for formatting, routine library usage already governed by tooling, or transient task mechanics.

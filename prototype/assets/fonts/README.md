# Prototype typefaces

The interaction prototype self-hosts three open-source typefaces:

- Public Sans variable — interface and guidance;
- Source Serif 4 variable — determinations and major institutional statements;
- IBM Plex Mono regular — identifiers and procedural metadata.

Each font is distributed under the SIL Open Font License 1.1. The corresponding license text is stored beside the font file. These assets are part of the approved prototype direction; the production application's font-loading strategy remains a later implementation decision.
